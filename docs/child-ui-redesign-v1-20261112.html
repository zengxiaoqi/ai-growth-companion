UI DESIGN SYSTEM · 孩子端 / CHILD MODE

灵犀伴学 · 孩子端 UI 重构 v1首页 / 学习 / 小犀对话

面向 3–6 岁、识字有限、以点按和语音为主 的学龄前儿童。这一版把「四张等高撞色、满屏加载失败文案的大卡」重排为 一个 2 秒内就能看懂的主任务、一个常驻的 AI 伙伴入口、一行可滑动的探索小卡；让「小犀」成为主角，让每一次点击都有回应。 三台手机均可独立操作，点击底部导航、主按钮、探索卡与聊天输入框即可体验。

提示：点击任一设备上方的序号可将其设为放大对象；「成就 / 我的」不在本次三屏重构范围内，点击会给出说明。

02 · 现状问题诊断

基于截图与 child_home_screen.dart / learning_home_screen.dart / ai_chat_screen.dart 实际结构。

  • 零视觉层级：4 张卡等高、等宽、等圆角、等内边距，眯眼测试完全失败，看不出哪里是主入口。
  • 首屏全是失败态：天气 / 国家 / 数字 / 冷知识四个外部接口一旦不可用，孩子第一眼看到的是 4 句「看不到 / 暂时不可用 / 无法获取」。
  • 没有主行动：首页无「开始学习」、无今日任务、无进度，孩子不知道打开 App 要做什么。
  • 色彩无语义：蓝 / 绿 / 橙 / 浅蓝随机分配且互相撞色；白字压在浅渐变上对比度不足（部分低于 3:1）。
  • 操作不方便：刷新图标约 24px，远小于 44px 触控下限；整卡不可点、无底部主导航承接、无点击反馈。
  • 浪费纵向空间：每张卡约 130px 只承载一行字，信息密度失衡；IP「小犀」与星星 / 积分等成长反馈在首屏完全缺席。

03 · 设计上下文与原则

Users：3–6 岁儿童，家长在旁，手机 / 平板竖屏，单次 5–10 分钟。Job：知道今天做什么 → 一点就开始 → 完成后被鼓励。Brand：温暖、绘本感、玩具般俏皮、安全。

  • 一眼一件事：首屏只保留一个主 CTA，其余内容降级为探索，不与之争抢注意力。
  • 永远不说「不可用」：外部接口失败时回退到内置知识 / 插画，孩子看到的永远是内容而非报错。
  • 角色带路：小犀出现在问候、入口、聊天、空态四处，成为可识别的陪伴线索。
  • 可按压的实体感：2px 描边 + 4–6px 实体下阴影 + 按下位移，让 3–6 岁孩子「看得见能点」。
  • 先图形后文字：所有关键动作都有图形 + 大字号短句，文字只作补充，不依赖识字量。

06 · 落地建议（对接现有代码）

本稿是设计验证稿，未改动业务代码。确认方向后建议按下面顺序落地：

  • 先落 token：src/frontend/lib/theme/app_theme.dart 增补 paper / surface / ink / sun / coral / mint / tactileShadow；src/frontend-web/src/index.css 的 @theme 同步同名变量，并统一 Flutter childColors 与 Web --color-domain-* 目前不一致的科学 / 艺术 / 社会色值。
  • 再改首页信息架构：child_home_screen.dart 的 ChildHomeContent 顺序改为 问候+星进度 → 今日任务 Hero → 小犀入口 → 今天的小发现（横向）→ 快捷键；把 WeatherCard / CountryCard / NumberFactCard / FactCard / JokeCard 从「独立通栏大卡」改为统一 DiscoveryCard 组件，并各自配置内置兜底文案（接口失败时不再渲染「不可用」）。
  • 今日任务数据源：接 GET /assignments/child/:childId 取 status=pending 的首条，展示 activityData.title / domain / difficulty；无作业时回退到推荐内容 GET /recommend，仍无则给「今天自由探索」的图形化空态。
  • 学习页：6 个学科从列表改 2×3 大图标按钮（≥ 100px 高），补「继续上次」与今日进度环（数据来自 GET /learning/today/:userId）。
  • AI 对话页：把语音输入从输入框里的小图标提升为 48px 主按钮（3–6 岁主要输入方式），快捷提问改为图形 chips，AI 气泡常驻「读给我听」按钮对接现有 TTS；「小犀正在想…」承接现有 SSE 流式状态。
  • 验收清单：44px 触控下限、点击必有反馈、失败态永不出现技术文案、首屏 2 秒内能指出主任务、对比度 ≥ 4.5:1、reduced-motion 下动画停止。
