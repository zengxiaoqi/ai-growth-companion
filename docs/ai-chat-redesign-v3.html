⑥ 消息操作
  • 1长按 / 底部操作条双通道：长按任意 AI 消息弹出底部动作面板，同时消息底部保留最高频的复制/朗读/重答三键。
  • 2动作带说明：「朗读出来」右侧标出音色来源，孩子和家长都能预期结果。
  • 3删除单独染色：唯一破坏性操作，红棕色 + 置底，减少误触。
Before · 现状问题
  • 输入栏五个平级圆钮 + 整宽白底条，工具与输入框视觉权重相同，孩子不知道从哪开始。
  • 「历史会话」「文件」「语音」三个入口分散在页脚与顶栏，认知负担高。
  • AI 消息是一张 85% 宽白卡，里面再套游戏卡，边框套边框共 3 层。
  • 思考过程是 40px 高的灰框，默认占位却几乎没人点。
  • 每个游戏都是完整卡 + 大按钮，一屏出现多个「开始游戏」。
After · 重构结果
  • 一个胶囊装下输入、工具、语音、发送；页面只剩「内容 + 一个输入框」两个视觉块。
  • 所有能力收敛到「＋」：拍照 / 相册 / 文件 / 打电话 / 英语陪练 / 历史 / 导出 / 清空。
  • AI 正文去卡化，只剩正文 + 头像；卡片只给真正可交互的内容。
  • 思考过程压成 28px 胶囊，收起时不打断阅读节奏。
  • 游戏卡主次分明：首个完整、其余折叠成单行，滚动长度减约 40%。
3–4 岁（level 0）单独一版：大字、大话筒、无思考过程、无复制重答， 输入框只保留「拍照 / 相册」两格。
