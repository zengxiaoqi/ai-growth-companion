03 · 相对 v1 的「卡通化」手法

  • 角色变大、会动：小犀 72px → 92px，重画大眼白 + 高光 + 微笑嘴 + 挥手小手，随主题换装（粉 / 绿 / 紫），常驻 bob 摆动。
  • 更胖的形状：主圆角 26 → 34px，按钮 18 → 26px，图标底 17 → 19px，整体更接近软胶玩具。
  • 更粗的描边：2px → 3px 实色描边（深色主题用亮紫），配 5–7px 实体下阴影，按下压 4px。
  • 贴纸感：主任务卡 -1.2° 倾斜 + 胶带装饰，探索卡 hover 再歪 1.5°，打破 v1 的规整网格。
  • 对话气泡：问候语改成带小尖角的气泡框，文案口语化（「今天先玩这个吧！」）。
  • 装饰元素：云朵 / 棒棒糖 / 树叶 / 星球按主题切换，背景加双色柔和光斑。
  • 图形化激励：低龄档用 3 颗可弹跳的大星星替代数字进度条，减少识字依赖。
  • 克制底线：动效均 < 0.5s 且遵循 prefers-reduced-motion；所有触控目标 ≥ 44px，装饰不遮挡内容。

04 · 落地建议

  • 主题来源：读用户 / 内容已有的 ageRange（'3-4' / '5-6'）自动选皮肤；4–5 岁过渡档可由家长在设置里手选，或按 birthDate 计算。
  • Flutter：把本稿变量做成 ThemeExtension<LingxiChildTheme>（约 25 个字段），MaterialApp 按 ageRange 注入；卡片组件统一读 context.extension，禁止在组件里硬编码色值。现有 app_theme.dart 的 childColors 可映射为 --s1..--s6。
  • React Web：在 index.css 里按 [data-theme="candy|forest|space"] 定义同名变量，根节点由 AuthContext 的 user.ageRange 写入 data-theme，Tailwind 用 @theme inline 引用变量即可，组件零改动。
  • 密度差异：不要把三档做成三套组件，而是同一组件读 theme.level 控制 subjects / chips / textInput / tasks 四个开关，避免三份代码分叉。
  • 深色皮肤注意：星际小队要单独校验上传图片、视频封面、Emoji 在深底上的可读性；护眼模式下建议自动回退到森林主题。
  • 与 v1 的关系：v1（docs/child-ui-redesign-v1-20261112.html）是「克制绘本版」，本稿是「卡通主题版」，两者共用同一套信息架构，可择一落地或做成家长端可切换的皮肤。
