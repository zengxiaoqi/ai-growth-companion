家长提示
低龄档里
孩子看不到什么
所有"管理型"和"二次操作"都被移出孩子的视线，需要时从家长端进入。
✕ 思考过程
孩子不需要看推理链，长文本还会挤压首屏；家长端可查看完整记录。
✕ 复制 / 重答 / 三点菜单
都是"对一个回答不满意"的元操作，3–4 岁没有这个心智模型，只会造成误触。
✕ 导出 / 清空 / 设置
归入「历史会话 → 更多」，需要家长锁（长按标题 2 秒）才能进入。
✓ 保留的三个动作
说话（大话筒）、拍照（相机键）、听一遍（大喇叭）。全部 ≥ 44px。
* 具体家长锁样式见「家长端-设置」设计稿，本页只声明边界。
⑥ 视线边界
  • 1减法优先：低龄版每增加一个按钮，误触率与放弃率都会上升，所以先问"能不能不给"。
  • 2家长能力不减少：只是换了入口 —— 历史会话页 + 家长锁，功能一个不少。
标准版（4–6 岁 / 家长）
  • 正文 14.5px / 1.62，思考过程 28px 胶囊可展开
  • 输入栏：＋ 工具 / 英语陪练 / 话筒 / 发送
  • 工具面板 4 格：拍照、相册、文件、英语陪练
  • 消息底部：复制 / 朗读 / 重答
  • 卡片：首个完整 + 其余折叠成 mini-row
