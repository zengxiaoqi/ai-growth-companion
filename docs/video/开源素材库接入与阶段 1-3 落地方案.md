# 开源素材库接入与阶段 1-3 落地方案

## Summary
可以接入开放素材库，但默认策略采用 **CC0 优先 + 半写实科普风格**。第一优先级是本地高质量素材库，第二优先级是 Openverse/Wikimedia 等开放素材 API，最后才回退到当前代码 SVG 简笔动画。依据：Openverse 提供开放授权图片/音频搜索，并返回 license、url、creator、mature、尺寸等字段；Wikimedia Commons 可通过 `imageinfo&iiprop=extmetadata` 获取许可证元数据；Kenney 官方说明游戏素材为 CC0 且无需署名。参考：[Openverse API](https://wordpress.github.io/openverse-api/reference/api/docs.html)、[Wikimedia Commons metadata](https://commons.wikimedia.org/wiki/Help%3AMachine-readable_data)、[Kenney Support](https://kenney.nl/support)。

## Key Changes
- 新增 `VisualAssetService`，负责把分镜里的主题、场景、动作解析成素材计划：
  - 输入：storyboard scene、topic、domain、ageGroup、action/habitat/tags。
  - 输出：`SceneVisualAssetPlan`，包含 `mainCharacter`、`background`、`overlays`、`licenseInfo`、`sourceProvider`、`qualityScore`。
  - 默认只接受 `license=cc0/publicdomain`；CC-BY、CC-BY-SA、GPL 类素材第一版不自动进入渲染。
- 扩展 `DynamicRemotionManifest`：
  - 新增 `assets[]`，记录本地静态路径、原始来源、许可证、尺寸、用途。
  - scene 新增 `visualAssets`，例如 `characterAssetSrc`、`backgroundAssetSrc`、`overlayAssetSrc[]`。
  - `sceneAssetSummary` 增加 `assetProvider`、`assetLicense`、`assetQuality`，日志能直接看出是否用了真实素材。
- Remotion 组件改成 asset-first：
  - 使用 Remotion `<Img>` + `staticFile()` 加载本地素材。
  - 老虎、森林、河流、夜晚背景优先使用图片资产，当前 `TigerSvg` 只作为最后兜底。
  - 动画从“手写老虎形状”改为“图片分层导演”：镜头推进、轻微呼吸、横向奔跑、水波遮罩、吼叫声波、知识标签指示线。
- 新增开放素材 provider：
  - `LocalAssetProvider`：读取 `src/video-remotion/public/assets/lesson/manifest.json`。
  - `OpenverseProvider`：搜索 `tiger / forest / river` 等英文关键词，过滤 `license=cc0`、`mature=false`、最低尺寸。
  - `WikimediaCommonsProvider`：作为 Openverse 不足时的补充，使用 extmetadata 验证 Public Domain/CC0。
  - `KenneyProvider`：作为卡通背景、装饰、通用自然元素的可选 CC0 来源；动物真实度不足时不作为主动物来源。
- 素材缓存与合规：
  - 外部素材下载到 `src/video-remotion/public/.generated/assets/<hash>/`。
  - 同步写入 `asset-manifest.json`，保存 `sourceUrl`、`landingUrl`、`license`、`creator`、`provider`、`downloadedAt`。
  - 下载失败、尺寸过小、许可证不符、疑似非图片时跳过，不阻塞整体生成。

## Phase 1-3 Implementation
- 阶段 1：本地高质量素材库优先
  - 建立 `public/assets/lesson/manifest.json`，先覆盖老虎主题：`tiger-standing`、`tiger-running`、`tiger-swimming`、`tiger-roaring`、`forest-day`、`forest-night`、`river`、`water-splash`。
  - 动态 Remotion 生成时先查本地 manifest，命中后把素材路径写入 scene props。
  - 验收标准：老虎主题不再出现默认 `TigerSvg`，日志显示 `assetProvider=local`，抽帧中主体动物来自图片资产。
- 阶段 2：开放素材库自动补足
  - 实现 provider 顺序：`local -> openverse -> wikimedia -> svgFallback`。
  - Openverse 查询默认加 `license=cc0`、`category=photograph/illustration`、`mature=false`，下载前校验宽高不低于 `512x512`，背景不低于 `1280x720`。
  - Wikimedia 只接受 extmetadata 明确为 Public Domain/CC0 的图片；无法验证许可证则拒绝。
  - 验收标准：本地无素材的新主题能自动下载 CC0 素材并缓存，manifest 保留来源元数据。
- 阶段 3：高质量分层动画导演
  - 生成组件根据 `visualAssets` 选择布局模板：动物登场、外形标注、栖息地、能力展示、总结复习。
  - 主体动物图做轻微缩放/位移/裁切遮罩；背景做 parallax；水花、声波、箭头、关键词独立层动画。
  - 增加视觉验收：每个 scene 至少一个非文字主视觉资产；主视觉面积达到画面 15% 以上；纯文本画面直接降级失败并换 provider。
  - 验收标准：“认识动物老虎”生成 `dynamicRemotion=true`，日志包含 `assetProvider=local/openverse`、`license=cc0`、`narration audio generated 5/5`，MP4 有音轨且抽帧不是纯文字或简笔 SVG。

## Test Plan
- 单元测试：
  - 本地 manifest 命中时，scene props 包含 `characterAssetSrc/backgroundAssetSrc`。
  - Openverse 返回 CC0 且尺寸合格时，素材被缓存并写入 manifest。
  - Openverse/Wikimedia 返回 CC-BY-SA、GPL、未知 license、mature 或尺寸过小时拒绝使用。
  - 动态 Remotion 有图片资产时渲染 `<Img src={staticFile(...)}`，无资产时才回退 SVG。
- 集成测试：
  - 删除本地老虎素材后，模拟 Openverse CC0 返回，确认生成仍成功。
  - “认识动物老虎”完整任务日志包含素材来源、许可证、音频生成数量和 `dynamicRemotion=true`。
  - 用 `ffprobe` 验证音轨；抽取 3 帧确认主视觉资产存在且非纯文本。
- 回归测试：
  - 外部网络失败时不影响本地素材生成。
  - CC0 素材缓存重复命中时不重复下载。
  - 固定 Remotion/HyperFrames 降级路径保持可用。

## Assumptions
- 默认授权策略：只自动使用 CC0/Public Domain；署名型许可证先不进入自动链路。
- 默认视觉风格：半写实儿童科普，动物主体尽量真实，背景和标注保持柔和卡通化。
- 第一版不接付费素材、不接不稳定的网页爬虫，只接可验证元数据的 API 或本地 manifest。
- 现有 SVG 动物保留为兜底，但不再作为高质量动态 Remotion 的首选视觉资产。
